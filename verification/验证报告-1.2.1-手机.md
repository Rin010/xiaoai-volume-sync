# 小爱音量设置 1.2.1 手机验证

验证设备为小米 23116PN5BC / shennong，HyperOS OS3.0.306.0.WNBCNXM，Android 16 / API 36。当前用户的小爱为 7.13.21.0017，versionCode 507013021。

问题原因：1.2.0 只允许平板小爱 7.13.33.0017 的已检查混淆结构启用直接媒体模式；手机版的流工具类也由 `k00.o` 变为 `d00.o`，因此模块保留保护性停用，实际播放仍为助手流 11 / USAGE_ASSISTANT 16。

1.2.1 对两个已检查版本建立显式类映射。手机 APK 的 DEX 方法表确认 `d00.o.getVoiceAssistStreamType(): int`，以及媒体静音、自动音量和 `ensureXiaoaiVolume()` 的签名与现有 Hook 一致。

诊断构建在手机小爱主进程内读回：

```json
{"selectedMedia":true,"internalMuteBlocked":true,"volumeFloorBlocked":true,"playbackStarted":true,"playbackUsesMedia":true,"mediaIndexUnchanged":true,"media":8}
```

对应运行日志为 `PLAYBACK AudioTrack stream=3 usage=1`。这证明小爱选择媒体流、显式助手 AudioTrack 转为媒体用途、内部媒体静音和最低音量调整均受开关控制，且测试前后的媒体保存档位都是 8。正式构建不注册诊断广播入口。

APK 构建过程的音量换算与按键隔离测试通过，v3 签名和 ZIP 对齐验证通过。手机的蓝牙、听筒/SCO 路径和完整语音对话听感未在本次测试覆盖。

正式 APK SHA-256：`7844AFF1B147091EE152AB83FD0FBDAEAEAFBF32C9F2FD5189E87AD8416FD15A`。
